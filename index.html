📱 ¿32 o 64 bits en Android?

En la mayoría de los teléfonos actuales puedes utilizar Nexorax64.apk. Si tu dispositivo es antiguo o sabes que utiliza 32 bits, utiliza Nexorax32.apk.

💻 ¿Qué descargo para mi PC?

Si vas a utilizar Nexora en una computadora Windows, selecciona “Descargar para Windows”. El archivo descargado contiene la aplicación para PC.

Por eso Android puede mostrar una advertencia de seguridad o pedirte permiso para instalar aplicaciones desde esta fuente. Si aparece, sigue las instrucciones de tu dispositivo únicamente si reconoces que estás instalando Nexora.

¿Qué puedo hacer con Nexora?

Puedes gestionar ventas, inventario, productos, sucursales, movimientos, gastos, reportes y mucho más, además de utilizar Mi Tienda Online y las funciones de Red Nexora.

¿En qué dispositivos funciona?

Nexora está disponible para Android y Windows mediante las descargas que aparecen directamente en esta página.

¿Cuál APK debo instalar?

Para la mayoría de los dispositivos actuales se recomienda la versión de 64 bits. La versión de 32 bits está pensada para dispositivos compatibles con esa arquitectura.

¿Por qué Android muestra una advertencia?

Al instalar una aplicación mediante APK fuera de Google Play, Android puede mostrar una advertencia o solicitar permisos. Esto forma parte de las protecciones del sistema para aplicaciones instaladas desde fuentes externas.

¿Puedo usar Nexora en una PC?

Sí. Descarga la versión para Windows desde el botón correspondiente y tendrás una experiencia pensada para trabajar cómodamente en una pantalla grande.

¿Dónde están las descargas?

En esta misma página. Los botones “Descargar Android” y “Descargar para Windows” son accesos directos a los archivos de Nexora.
